

# 📚 Storypix Draft

**Storypix-Draft** is a draft model of a story creation website featuring **user authentication** (Sign Up, Login, Forgot Password) and a basic **Home Page** layout. This project is built with **React** using **Create React App** and serves as the foundational version for a full-featured storytelling platform.

🔗 **GitHub Repo**: [https://github.com/hariprasath-0ffl/Storypix-Draft](https://github.com/hariprasath-0ffl/Storypix-Draft)

---

## 🚀 Getting Started

To get the project running locally, follow these steps:

### 1. Clone the Repository

```bash
git clone https://github.com/hariprasath-0ffl/Storypix-Draft.git
cd Storypix-Draft
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Application

```bash
npm start
```

The app will run in development mode.
Open [http://localhost:3000](http://localhost:3000) in your browser to view it.

## 📜 Scripts

Available scripts in the project directory:

### `npm start`

Runs the app in development mode.
Automatically reloads when code changes.

### `npm test`

Launches the test runner in interactive watch mode.
More info: [Running Tests](https://facebook.github.io/create-react-app/docs/running-tests)

### `npm run build`

Builds the app for production in the `build` folder.
Optimizes the app for performance and minifies files.

**Use with caution** — this command exposes all configurations and dependencies.
